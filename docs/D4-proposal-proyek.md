# D4 · Proposal Proyek

* **Judul Proyek:** SPACENEST (System for Faculty Space & Resource Management) – Modul Pelaporan Kerusakan Fasilitas Fakultas Teknik dan Sains Terapan.
* **Latar Belakang Singkat:** Sistem pelaporan manual via grup/chat pribadi sering membuat informasi tercecer dan penanganan lambat. SPACENEST hadir sebagai solusi terpusat berbasis web.
* **Tujuan (Objective):** Menyediakan platform web yang transparan, terstruktur, dan responsif untuk mempercepat proses pelaporan hingga monitoring penanganan kerusakan fasilitas kampus.
* **Metodologi Pengembangan:** Menggunakan pendekatan Hybrid (Perencanaan awal terstruktur ala Waterfall, dilanjutkan dengan eksekusi iteratif berbasis Sprint 2 mingguan).
* **Target Luaran (Deliverables):**
  * Repositori kode sumber di GitHub (`src/`).
  * Dokumentasi lengkap proyek dari D1 sampai D9 di folder `docs/`.
  * Aplikasi web SPACENEST siap uji coba (staging/deployment lokal).
